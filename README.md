# Library Management System (Java)

## 📌 Description
A console-based Library Management System built using Java.  
It allows users to manage books with file storage support.

## 🚀 Features
- Add Book
- View Books
- Search Book
- Delete Book
- Update Price
- Find Costliest Book
- File Storage using books.txt

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling (BufferedReader, FileWriter)
- Menu-driven program

## 📂 File Format
Books are stored in:
Title,Author,Price

Example:
Harry Potter,J.K.Rowling,500

## ▶️ How to Run
1. Compile:
   javac Main.java
2. Run:
   java Main
